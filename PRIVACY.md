Privacy Policy for Horizon Connect
Date: May 5, 2026

Horizon Connect helps users connect to proxy servers and manage proxy subscriptions

Developer
Developer: Horizon ltd

Contact email: 
horizonvpn7@gmail.com

What data the app uses
Horizon Connect may use:

proxy keys, subscription links, server addresses and connection parameters
selected server, connection status, ping and connection time
network state to understand whether internet access is available
notifications to show an active proxy connection
technical crash and stability data through Firebase
The app does not request precise geolocation, contacts, photos, SMS, microphone, camera or permission to install third party apps

Data sharing
We do not sell personal data

The app may use third party services for its operation:

Google Firebase for crash and stability diagnostics
proxy servers for connection processing
Android system services for proxy, network and notifications
Proxy traffic
When proxy is enabled, the device internet traffic goes through the selected proxy server

Horizon Connect does not sell browsing history, DNS requests, traffic content or user activity data

The server may technically process IP address, connection time and traffic volume only to operate the proxy, protect the service and fix problems

Why data is needed
Data is needed to:

connect to proxy
import subscriptions
show connection status
check server ping
fix errors and improve stability
protect the service from abuse
Data storage
Proxy keys, subscriptions and settings are stored on the device until the user deletes them or removes the app

Firebase diagnostic data is stored according to Google Firebase rules

Security
We use standard Android mechanisms and protected connections where needed for the app to work

Children
Horizon Connect is intended for users aged 16-17 and users aged 18 and older

The app is not specifically intended for children under 16

User rights
The user can:

delete subscriptions and keys in the app
clear app data in Android settings
delete the app
Changes
This policy may be updated

The new version will be published on this page

Политика конфиденциальности Horizon Connect
Дата: 5 мая 2026

Horizon Connect помогает подключаться к прокси серверам и управлять прокси подписками

Разработчик: Horizon ltd

horizonvpn7@gmail.com

Какие данные использует приложение
Horizon Connect может использовать:

прокси ключи, ссылки подписок, адреса серверов и параметры подключения
выбранный сервер, статус подключения, пинг, время подключения
состояние сети, чтобы понимать есть ли интернет
уведомления, чтобы показывать активное прокси подключение
технические данные о сбоях и стабильности через Firebase
Приложение не запрашивает точную геолокацию, контакты, фото, SMS, микрофон, камеру и разрешение на установку сторонних приложений

Передача данных
Мы не продаем персональные данные

Для работы приложения могут использоваться сторонние сервисы:

Google Firebase для диагностики сбоев и стабильности
прокси серверы для обработки подключения
системные сервисы Android для прокси, сети и уведомлений
Прокси трафик
Когда прокси включен, интернет трафик устройства идет через выбранный прокси сервер

Horizon Connect не продает историю сайтов, DNS запросы, содержимое трафика и данные активности пользователя

Сервер может технически обрабатывать IP адрес, время подключения и объем трафика только для работы прокси, защиты сервиса и исправления проблем

Зачем нужны данные
Данные нужны чтобы:

подключать прокси
импортировать подписки
показывать статус подключения
проверять пинг серверов
исправлять ошибки и улучшать стабильность
защищать сервис от злоупотреблений
Хранение данных
Прокси ключи, подписки и настройки хранятся на устройстве, пока пользователь не удалит их сам или не удалит приложение

Диагностические данные Firebase хранятся по правилам Google Firebase

Безопасность
Мы используем стандартные механизмы Android и защищенные соединения там, где это нужно для работы приложения

Дети

Приложение не предназначено специально для детей младше 16 лет
